Search bar & Ask Workspace front and center, with the reference card's three-question capture surfaced as a horizontal filter row. Folders demoted to a quick-jump list because retrieval, not browsing, is the goal.

What's shared across all three

Cream canvas #FAF7F2, coral accent #D97757, Cormorant Garamond for titles, Inter for UI text, Caveat reserved for editorial moments. Tag pill shape and tag bucket colors match the reference card and BRAND.md exactly.

How they differ

A mirrors the reference card's tiered list verbatim — best when teaching the model. B elevates recent docs & folder browsing — best for daily users. C puts search and the three-question capture flow first — best once the taxonomy is internalized.

Suggested next step

Pick one direction (or a hybrid: B's grid + C's hero search is a strong combo) and we can produce the folder-detail screen, capture review, and the action sheet as a matching set.
