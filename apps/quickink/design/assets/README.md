# DEPRECATED — see design/exports/ instead

This folder is the **first-pass, geometric-Q** asset bundle generated by
`generate-assets.mjs`. It is no longer the source of truth.

The brand was finalized on a different mark — the **calligraphic Q** the
designer hand-rendered. The authoritative assets live in:

- `design/source/quickink-icon-1024.png` — the original calligraphic
  artwork (master input).
- `design/exports/` — every derived deliverable: marks, wordmark, lockups,
  splash, store icons, UI icon set, social, onboarding, App Store
  screenshots.
- `design/BRAND.md` — the brand guide; full asset index at the bottom.

The live app already points at the new assets:

- iOS `Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`,
  `QuickInkMark.imageset`, `QuickInkWordmark.imageset`,
  `Icon{Name}.imageset` (six icons).
- Android `res/drawable/ic_launcher_*.xml`,
  `res/drawable-nodpi/splash_mark.png`, `splash_wordmark.png`,
  `res/drawable/ic_{name}.xml` (six icons), `res/values/{colors,themes}.xml`.

## Why this folder is still here

The build sandbox that produced the new exports cannot delete files; it
can only overwrite. The geometric-Q SVGs and the generator script that
produced them are left in place rather than blanked out. If you want a
clean slate, delete this folder from your terminal:

```bash
cd /Users/achalindiresh/workspace/releaf/apps/quickink
rm -rf design/assets
```

Nothing in the live app, the Xcode project, or the Gradle build references
this folder, so deletion is safe.

## What was different about the old artwork

The geometric Q in this folder is a code-generated approximation: a
circle-ring path with a curved tail and a coral disc. It was produced
during the first prototype pass before the designer painted the
calligraphic version. Visually it reads as a logo, but it lacks the
variable stroke weight and the brush-style flourish of the final mark.

If you ever need to regenerate first-pass placeholders (e.g. for a
fork or a sister app), `generate-assets.mjs` still runs — but for
QuickInk itself, **everything new should go through `design/exports/`**
and be referenced from `design/BRAND.md`.
