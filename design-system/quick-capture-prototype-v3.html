What this version does

This is v3 — your tile-grid reference applied verbatim with the six modes you named. v1 had Note · Photo · Voice · Scan · Link · From Clipboard. v2 promoted Scan to a hero with pre-tag categories. v3 drops Scan and Link from the primary grid, swaps in the page-context modes (Todo · Contact · Pin), and pulls search and calendar up to the header so they're reachable without dismissing the sheet.

Header buttons

Search. Routes to releaf://search via the existing NAV_GRAPH.md entry. Sheet dismisses on tap and re-opens on back. The same affordance replaces the per-screen search icons in the Home and Notepad headers, which was already the recommendation in DAILY_CAPTURE_UX.md §4.2.

Calendar. Replaces the inline calendar pill that lives in the current QuickCaptureSheet.kt. Tap opens the full calendar route (features/calendar/CalendarScreen.kt) instead of expanding the panchanga panel inline — moving it out of the sheet keeps the sheet height predictable and matches what users expect from a calendar icon. The inline panchanga panel still ships, just at a destination URL, not inside the capture sheet.

Where Scan went

Not on this grid by design. Three places it could live:

(a) Long-press the Photo tile. Photo and Scan share the camera flow — long-press could swap to "Scan a document" with edge detection on. Cheap to implement; risk is that nobody discovers it.

(b) Inside the page-detail editor. The page-detail tab bar already has Scans as a mode (per CaptureMode.kt). Quick capture's job is the daily flow; one-off structured captures live in their actual home.

(c) A 7th tile — accept the asymmetric 3+3+1 layout. Doable but visually messy.

Recommend (a) + (b): long-press Photo for quick scan, plus the page-detail entry for deliberate scanning sessions. v2's "scan-as-hero" framing belongs on a dedicated Scans surface, not in the daily capture sheet.

Color rationale

Six different soft washes so the modes are individually recognizable at a glance — same idea as the original reference, but without the special coral "From clipboard" tile (no longer in the mode set) and with the new Pin/Contact/Todo modes getting unique tints rather than reusing an existing one. All six washes already exist in design-tokens.json as color.semantic.*Soft; this is composition, not new tokens.

Open questions

1 · Should "Notes" be the first tile or the most visually distinctive?
Notes sits top-left as the highest-frequency mode in a journaling app. Its washed-grey icon-chip reads as the most muted of the six though, which is the inverse of "most important." Consider: Notes gets a cream/coral wash to match its frequency, with the muted treatment moving to a lower-frequency tile.
2 · "Pin" or "Place" or "Location"?
Existing schema calls it locations; existing CaptureMode calls it Location; v2 used "Place." You named it Pin here — friendlier and more affordance-y (a pin is something you place). Recommend: ship "Pin" as the user-facing label; keep parent_* column names and kind enum unchanged. UI label only.
3 · Does long-press on a tile open a "Capture into…" picker?
The subtitle says "long-press a tile to choose elsewhere" — implies yes. The interaction should swap the grid in place with a target list (Today · Yesterday · A specific page · Pick later) rather than open a nested modal. Same recommendation as v1, lower risk on Android compose-foundation. Confirm: "elsewhere" means parent picker, not destination type.
4 · Hint copy under each tile — keep or drop?
"keyboard up", "camera", "tap or hold FAB", "checklist item", "phone · email", "tag this place." All six fit. Useful for first-time users; visual noise for repeat users. Recommend: hide hints after the first 7 days; the tiles' icons + labels carry enough signal once the muscle memory is there.

Implementation footprint

One file changes meaningfully on each platform. Android — QuickCaptureSheet.kt: drop the calendar-toggle pill, replace the LazyColumn with a LazyVerticalGrid(GridCells.Fixed(3)) of CaptureTile composables, add a Row in the header for the search and calendar icon buttons. iOS — QuickCaptureSheet.swift mirrors with LazyVGrid. CaptureMode.kt: add Notes, rename Location → Pin for display, drop Overview and Scans from the quick-capture set (they remain in the page-detail tab bar). No SQL migration; no nav graph change.
